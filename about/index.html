SOURCES, PEOPLE, AND A STARTING POINT

One game opened
a much bigger door.

Dirge of Cerberus: Lost Episode began Wakka's Android bridge work. This catalog is a return to those DoJa roots, built around the source trails preserved by a much wider community.

The preservation work comes first

Keitai Archive describes a community effort preserving Japanese feature-phone games and other media. Keitai World Launcher, developed by Yuvi and its contributors, brings together resources and emulators for several keitai platforms. Keitai Wiki provides broader historical documentation.

Original dumping, recovery, translation, and emulator credits remain with those projects and their credited contributors. The launcher catalog does not supply complete per-entry contributor credits; none are invented here. Source corrections and missing credits are welcome.

Dirge's place in the story

In his August 3, 2026 account, Yuvi describes restoring access to the full Lost Episode release using recovered SD-card data, and credits Naoya Shinota and other contributors. The account explains the work behind the preserved game. Wakka's bridge and this catalog follow that preservation effort.

The Dirge record retains the standard source listing, trial, and English-patch listing separately, together with the source's SD-data references and trial-variant labels.

What counts as DoJa here?

Keitai Archive's resources distinguishes the DoJa and STAR SDK families. This catalog uses the launcher's explicit Emulator=doja field. A DoCoMo carrier label alone is too broad: other runtimes and media also belong to that carrier.

Counting entries and title records

The source XML snapshot contains 2,818 entries, including 2,149 explicitly labeled DoJa. Those become 2,067 browsing records. A record can contain an original listing, a trial, and translation patches. Recognized patch prefixes and bracketed, parenthesized, or explicit Trial Version / Demo Version suffixes are removed only for grouping. One documented display-name alias joins “Final Fantasy VII Snowboarding” to “Final Fantasy 7 Snowboarding.” Other title differences remain distinct.

These are title and application records, rather than a count of distinct retail games. Device variants remain labels within their source entry; they are not counted as extra catalog entries. Grouping names does not verify byte equivalence, completeness, or compatibility between editions.

Names, language, and unknowns

English and Japanese source-title fields are preserved, including half-width characters. Exact patch labels identify 61 English-patch entries and 26 Chinese-patch entries. An entry without a patch label is shown as unmarked; its language is not inferred from its title. Trial labels are taken from explicit source-title suffixes.

Carrier-specific private-use glyphs appear as ◇ in the interface; original code points remain in the JSON export. Publication years, publisher/developer credits, translator identities, SDK version requirements, and playability are left open when the metadata does not establish them.

What an SD-data reference means

9 entries have a separate SD-data URL in the source metadata. This index records the presence of that reference without fetching its contents. Presence is not a tested requirement, and absence does not prove that an application is self-contained. 975 entries carry variant labels, which remain exact source text.

Two public metadata snapshots

The primary source is the XML game list configured by the official Keitai World Launcher download. Only its configuration metadata was read from the launcher ZIP. No launcher binaries were executed and no game packages, screenshots, SDKs, or SD-data packages were retrieved.

The public website CSV is used as a second name reference. 2,117 included entries have an exact name match there; the remaining 32 are exact-string differences, not a claim that those games are missing. Source names are retained without guessing replacements.
